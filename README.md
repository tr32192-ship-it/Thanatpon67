# 💻 E-Portfolio | ครูผู้สอนด้านเทคโนโลยีและการเขียนโปรแกรม

เว็บไซต์แฟ้มสะสมผลงานอิเล็กทรอนิกส์ (E-Portfolio) สำหรับครูผู้สอนด้านเทคโนโลยี วิทยาการคำนวณ และการเขียนโปรแกรม พัฒนาด้วย **HTML5, CSS3 และ Vanilla JavaScript** ในไฟล์เดียว (`index.html`) รองรับการแสดงผลทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ และพร้อมเผยแพร่ผ่าน **GitHub Pages** ทันที

---

## ✨ คุณสมบัติหลัก (Features)

- **โครงสร้างครบถ้วน 4 ส่วนหลัก:**
  1. **หน้าแรก (Hero Section):** แนะนำตัวตน บทบาทหน้าที่ และปุ่มเข้าถึงผลงาน/GitHub อย่างรวดเร็ว
  2. **แนะนำตัว (About Me):** ข้อมูลส่วนตัว วุฒิการศึกษา รายวิชาที่สอน และทักษะด้านเทคโนโลยีการศึกษา
  3. **ผลงาน (Portfolio & Works):** การ์ดแสดงผลงาน สื่อการสอน และโครงงานนักเรียน พร้อมระบบกรองหมวดหมู่ด้วย JavaScript
  4. **กิจกรรม (Activities & Training):** ประวัติการอบรม การเป็นวิทยากร และกิจกรรมบริการวิชาการ
- **ดีไซน์ทันสมัย:** โทนสีน้ำเงิน-ขาว (Blue & White Theme) อ่านง่าย สบายตา พร้อมฟอนต์ **Prompt** รองรับภาษาไทยอย่างสมบูรณ์
- **Responsive Design:** ปรับขนาดหน้าจออัตโนมัติ (รองรับทั้ง Desktop, Tablet และ Mobile) พร้อมเมนู Hamburger สำหรับหน้าจอขนาดเล็ก
- **Zero Dependencies:** ไม่ต้องติดตั้ง Framework หรือ Library เพิ่มเติม เปิดใช้งานได้ทันทีผ่านเว็บเบราว์เซอร์
